# Kaimark — 최소 Chrome Extension

**Your bookmarks, upgraded.**

Kaimark는 기존 Chrome 북마크를 그대로 사용하면서 저장 후 제목·메모·폴더를 보강해 다시 찾기 쉽게 만드는 확장 프로그램입니다. 이름의 `Kai`는 改(고치다·개선하다), `mark`는 bookmark에서 왔습니다.

## 지금 되는 것

- 최근 Chrome 북마크 50개를 새 저장 순서로 표시
- 기본 **분류하지 않음 Inbox**: 편집 화면에서 한 번도 저장하지 않은 북마크만 표시
- **전체 최근**: 최근 50개 북마크 전체를 다시 확인
- 편집 화면에서 선택한 폴더 아래에 새 폴더 생성
- 목록에 상대 저장 시각 표시(예: `3일 전`)
- 메모가 있는 항목도 메모와 별도로 폴더 아이콘·폴더명·저장 시각을 정렬해 표시
- 사이트 파비콘을 표시하고, 불러오지 못하면 제목 첫 글자로 대체
- 개인 제목과 메모를 로컬에 저장
- 실제 Chrome 북마크 폴더로 이동
- 행 클릭: 현재 탭에서 열기 / `↗`: 새 탭에서 열기
- 북마크 삭제 시 연결된 개인 메타데이터 삭제

## Chrome에 설치하기

1. Chrome에서 `chrome://extensions`를 연다.
2. 오른쪽 위 **개발자 모드**를 켠다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누른다.
4. 이 `bookmark-finder-extension` 폴더를 고른다. 현재 Chrome에 로드된 경로를 유지하기 위해 폴더명은 바꾸지 않았다.
5. Chrome 도구모음의 퍼즐 아이콘에서 **Kaimark**를 고정한다.

## 의도적인 MVP 제한

- 개인 제목·메모는 `chrome.storage.local`에만 저장한다. 따라서 이 버전은 기기간 동기화되지 않는다.
- 기존 Chrome 북마크와 폴더 이동은 Chrome Sync 정책을 그대로 따른다.
- 분석·백엔드·로그인은 넣지 않았다. 이 흐름의 사용성을 먼저 검증한다.

## 다음 기술 검증

Chrome에서 북마크를 저장한 뒤, 팝업을 열어 최근 목록에 보이는지 확인한다. 편집 후 팝업을 닫았다 다시 열어 제목·메모가 남는지도 확인한다.
